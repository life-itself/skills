Life Itself and Rufus's agent skills now live in one public repo, [life-itself/skills](https://github.com/life-itself/skills), with a catalog of six skills (changelog, changelog-rollup, plan-for-delegation, planning, portfolio and project-planning) that work in both Claude Code and Codex. The new [install guide](https://github.com/life-itself/skills/blob/main/docs/install.md) shows how to use them, and session handoff now runs on a single beads pattern instead of `NEXT.md` files.
